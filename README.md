# Portfólio profissional

Projeto inicial em HTML5, CSS3 e JavaScript ES6+, sem React ou backend.

## Como executar
Abra `index.html` no navegador ou use Live Server no VS Code.

## Estado
Arquitetura inicial pronta, com navegação por âncoras, layout responsivo básico e animação de entrada com Intersection Observer.

Consulte `docs/arquitetura.md` para responsabilidades e próximos passos.
