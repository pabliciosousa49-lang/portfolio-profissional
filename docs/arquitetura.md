# Arquitetura — Portfólio profissional

## Objetivo
Portfólio responsivo e moderno construído com HTML, CSS e JavaScript puro, preparado para efeitos de rolagem.

## Estrutura e responsabilidades
- `index.html`: estrutura semântica e seções da página; importa CSS e JavaScript.
- `css/style.css`: identidade visual e estilos gerais.
- `css/responsive.css`: adaptações para telas menores.
- `css/animations.css`: estados e transições das animações.
- `js/main.js`: ponto de partida das interações gerais.
- `js/scroll.js`: Intersection Observer para revelar elementos ao rolar.
- `assets/images/`: imagens do projeto.
- `assets/icons/`: ícones do projeto.
- `docs/arquitetura.md`: documentação da arquitetura.

## Fase atual
Estrutura inicial funcional, com seções provisórias e efeito básico de entrada. Sem GSAP ou backend nesta fase. Conteúdo e design finais serão implementados posteriormente.

## Próximas etapas
1. Refinar layout com base na referência visual.
2. Substituir textos provisórios e adicionar mídias reais.
3. Implementar animações avançadas (GSAP/ScrollTrigger, se necessário).
4. Testar responsividade, acessibilidade e desempenho.
